# 🤖 Embodied AI Tracker

具身智能行业每日追踪器 - 用复古终端风格追踪前沿科技

## 特性

- 📰 每日自动抓取具身智能行业最新动态
- 🤖 可爱的小机器人展示学习进度
- 🎨 复古80年代CRT终端美学
- 🔄 GitHub Actions自动化更新
- 📊 分类展示：融资、产品、论文、新闻

## 数据来源

- arXiv - 学术论文
- Google News - 行业新闻
- Reddit (r/robotics) - 社区讨论
- Hacker News - 技术动态
- 36氪、机器之心 - 中文资讯

## 技术栈

- Python - 数据爬取
- GitHub Actions - 自动化
- GitHub Pages - 静态托管
- Claude API - AI摘要生成

## 本地运行

```bash
# 安装依赖
pip install -r requirements.txt

# 运行爬虫
python scraper.py

# 生成HTML
python generator.py
```
